```
- 发布/保存：主按钮，Loading 状态显示 Spinner + "保存中..."

```

## 4. 动态表单字段类型渲染规范 (基于 jj_field.field_type)

| field_type | 标识 | 渲染组件 | 关键 Props | 校验规则 | 长辈模式适配 |
|------------|------|----------|------------|----------|--------------|
| `text` | 单行文本 | `ElInput` | placeholder, maxlength, clearable | 长度、正则、必填 | 高度 56px，字号 18px |
| `textarea` | 多行文本 | `ElInput` (type=textarea) | rows, autosize, maxlength | 长度、必填 | 最小高 120px，字号 18px |
| `number` | 数字 | `ElInputNumber` | min, max, step, precision, controls-position | 范围、整数/小数、必填 | 步进器按钮 44×44px |
| `select` | 单选下拉 | `ElSelect` | options, filterable, clearable | 必填、选项合法性 | 下拉面板项高 48px |
| `radio` | 单选按钮组 | `ElRadioGroup` + `ElRadio` | options, button-style | 必填 | 按钮式，最小 88×48px |
| `checkbox` | 多选 | `ElCheckboxGroup` | options, max | 最大选择数、必填(至少1) | 复选框 24×24px |
| `date` | 日期 | `ElDatePicker` (type=date) | format, value-format, disabled-date | 日期范围、必填 | 面板字号放大，今日高亮 |
| `time` | 时间 | `ElTimePicker`/`ElTimeSelect` | format, value-format, is-range | 时间范围、必填 | 面板项高 44px |
| `datetime` | 日期时间 | `ElDatePicker` (type=datetime) | format, value-format | 日期时间范围、必填 | 分步选择：先日期再时间 |
| `image` | 图片上传 | `ImageUploader` (自定义) | max-count, max-size, accept, compress | 数量、大小、格式、必填 | 大区域点击上传，相机优先 |
| `member` | 成员选择 | `MemberSelector` (自定义) | mode: single/multiple, show-all | 必填、成员存在性 | 头像 56px，名字大字 |
| `relation` | 关联记录 | `RelationPicker` (自定义) | target-module, multiple | 记录存在性、权限 | 大卡片选择 |

## 5. 表单校验交互规范

### 5.1 校验时机

```
即时校验 (onBlur/onChange 延迟 300ms)：
- 格式类：邮箱、手机号、数字范围、日期格式
- 长度类：字符计数实时显示

失焦校验 (onBlur)：
- 必填项非空
- 业务规则：有效期 > 生产日期、剩余量 ≥ 0

提交校验 (onSubmit)：
- 全字段聚合校验
- 跨字段依赖：条件显示字段的校验
- 服务端唯一性：批号+药品名称组合唯一
```

## 6. 条件显示字段 (依赖渲染)

```

渲染逻辑：
- 依赖字段值变化时，实时计算显示/隐藏
- 隐藏时：字段值保留但不参与提交校验 (disabled)
- 显示时：平滑展开动画 200ms slide-down
- 标签前添加 🔗 图标提示"条件字段"

```

## 9. 保存草稿 / 自动保存

```
草稿策略：
├── 手动保存草稿：点击"保存草稿" → 本地 IndexedDB + 服务端 draft 表
├── 自动保存：用户停止输入 2 秒 → 防抖保存到本地
├── 草稿键：`draft:{module}:{id?:new}:{userId}`
├── 草稿过期：7 天自动清理
├── 编辑页进入：检测草稿 → 弹窗"发现未完成草稿，是否恢复？"
└── 草稿冲突：多人编辑同一记录 → 乐观锁 version 字段冲突提示

UI 提示：
- 输入框右上角：💾 草稿已保存 (灰色) / 💾 保存中... (蓝色旋转)
- 顶部通知栏：检测到草稿 → "恢复草稿" "丢弃"
```
