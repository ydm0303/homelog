## 7. 交互规范

### 7.1 字段值复制
```
长按/右键字段值 → Toast "已复制: 110101********1234" + 复制到剪贴板
支持批量复制：勾选多字段 → 底部栏「复制选中」
```

### 7.2 图片画廊手势
```
单击：进入全屏
双击/捏合：缩放
左右滑动：切换上一张/下一张
下滑：关闭全屏返回详情
长按：保存/分享/删除菜单
```

### 7.3 私密字段解锁 (管理员)
```
点击「解锁查看」→ Modal 二次认证
  ├─ 密码输入
  ├─ 指纹/面容 (WebAuthn)
  └─ 手势密码 (移动端)
解锁后：私密字段显示 5 分钟自动锁定
审计日志：记录解锁人、时间、字段
```

### 7.4 关联记录跳转
```
点击关联记录卡片 → 跳转对应模块详情页
面包屑保留：支持「返回上一级详情」
```
