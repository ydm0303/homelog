## 3. 交互状态定义

| 组件 | Default | Hover | Focus | Loading | Disabled | Error |
|------|---------|-------|-------|---------|----------|-------|
| 账号输入框 | 灰边框 | 主色边框 | 主色边框+阴影 | - | 灰背景 | 红边框+错误图标 |
| 密码输入框 | 灰边框 | 主色边框 | 主色边框+阴影 | - | 灰背景 | 红边框+错误图标 |
| 显示密码按钮 | 文字链接 | 下划线 | 轮廓环 | - | 灰色 | - |
| 主按钮(登录) | 主色填充 | 深主色 | 轮廓环 | 旋转spinner+禁用 | 灰色填充 | - |
| 次按钮(微信) | 白底主色边框 | 主色浅背景 | 轮廓环 | 旋转spinner+禁用 | 灰边框灰字 | - |
| 忘记密码链接 | 主色文字 | 下划线 | 轮廓环 | - | 灰色 | - |
| 创建家庭链接 | 主色文字按钮 | 深主色 | 轮廓环 | - | - | - |
| PWA安装横幅 | 底部浮动 | - | - | - | - | - |

## 4. 校验规则与错误文案

| 字段 | 校验时机 | 规则 | 错误文案 |
|------|----------|------|----------|
| 账号 | 失焦/提交 | 必填 | 请输入账号/手机号/邮箱 |
| 账号 | 提交 | 格式：手机号/邮箱/用户名 | 账号格式不正确 |
| 密码 | 失焦/提交 | 必填，6-20位 | 请输入密码 (6-20位) |
| 密码 | 提交 | 账号密码匹配 | 账号或密码错误 |

## 5. PWA 安装引导规范

```
触发条件：
✓ 用户已访问 ≥2 次
✓ 停留 ≥30 秒
✓ 未安装 PWA
✓ 支持 beforeinstallprompt 事件

显示位置：底部安全区上方固定条
显示时长：用户交互前持续显示
关闭方式：点击「稍后提鰹」→ 7 天不再弹出

文案：
主标题：添加「家记」到主屏幕
副标题：像原生应用一样使用，离线也能查看
主按钮：立即安装
次按钮：稍后提醒
```

## 6. 无障碍/适老化检查清单

- [ ] 所有输入框有关联 `<label>` 或 `aria-label`
- [ ] 密码输入框 `autocomplete="current-password"`
- [ ] 账号输入框 `autocomplete="username"`
- [ ] 主按钮 `type="submit"` 表单原生提交
- [ ] Tab 键顺序：账号 → 密码 → 显示密码 → 记住我 → 忘记密码 → 登录 → 微信登录 → 创建家庭
- [ ] 错误信息通过 `aria-live="polite"` 宣告
- [ ] 长辈模式：字号基准 16px→20px，按钮高度 44px→56px，触控目标 ≥48×48px
- [ ] 颜色对比度 ≥4.5:1 (WCAG AA)
- [ ] 支持密码管理器自动填充
