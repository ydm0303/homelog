## 4. 长辈模式开启时的差异 (Mobile)

```
关键变化：
├── 字号基准：14px → 18px (+4px)
├── 行高：1.5 → 1.7
├── 卡片内边距：16px → 24px
├── 按钮高度：40px → 52px
├── 触控目标：≥44×44px → ≥56×56px
├── 间距系统：基础单位 8px → 12px
├── 卡片圆角：8px → 16px
├── 图标尺寸：20px → 28px
├── 头像尺寸：32px → 44px
└── 简化信息密度：
    ├── 隐藏次要元数据（创建时间、操作人ID等）
    ├── 合并「即将到期药品」与「即将到期证件」为统一「⚠️ 即将到期」
    ├── 快捷入口从 6 个减为 4 个大图标
    └── 列表项单行显示，超出省略不换行

示例 - 长辈模式今日待办卡片：

│     我 · 今天               │
```

## 5. 组件规范 - 仪表盘专用组件

### 5.1 指标卡片

```
┌──────────────────────────────────────┐
│ 📋 待办                    [去处理 →] │ ← 图标 + 标题 + 数值 + 跳转链接
│ 进行中: 3                            │
│                                      │
│ ┌────────────────────────────────┐  │
│ │ ████████░░░░░░░░░░  60%        │  │ ← 进度条 (可选：完成率)
│ └────────────────────────────────┘  │
└──────────────────────────────────────┘

规格：
- 尺寸：最小 180×100px / 最大自适应
- 背景：白色 / 长辈模式：浅灰 #F5F5F5
- 阴影：0 2px 8px rgba(0,0,0,0.08)
- 圆角：12px (长辈 16px)
- Hover：阴影加深 + 轻微上浮
```

## 6. 交互规范

### 6.1 下拉刷新

```
触发区域：整个列表内容区
触发阈值：下拉 ≥ 60px
反馈：
  1. 下拉出现圆环加载动画 + "下拉刷新" → "释放刷新" → "正在刷新..."
  2. 刷新完成：Toast "已更新 X 条数据" + 列表平滑插入新数据
  3. 刷新失败：Toast "刷新失败，点击重试" + 保持下拉状态
```

### 6.2 空状态引导 (首次无数据时)

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│        📭                                                  │
│                                                            │
│    暂无待办事项                                            │
│    点击下方按钮创建第一个待办                              │
│                                                            │
│    ┌──────────────────────────────────────────────────┐   │
│    │        + 新增待办                                 │   │ ← 主按钮 大尺寸
│    └──────────────────────────────────────────────────┘   │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 6.3 快捷入口点击反馈

```
点击态：背景色加深 10% + 缩放 0.98
长按态 (仅长辈模式)：震动反馈 + 放大预览 Tooltip
跳转：页面切换 200ms slide-in 动画
```

## 7. 数据来源映射 (给前端/后端参考)

| 区块 | 数据来源 API | 关键字段 | 刷新频率 |
|------|-------------|----------|----------|
| 指标卡片 | `GET /api/dashboard/stats` | todo_pending, medicine_expiring, note_month_count, document_expiring | 进入页面/下拉刷新 |
| 今日待办 | `GET /api/todos?date=today&status=pending&sort=priority` | title, assignee, due_time, priority, tags | 进入页面/完成操作后 |
| 即将到期 | `GET /api/dashboard/expiring?days=30` | 药品/证件混合列表、过期时间、剩余量/天数 | 进入页面/每日定时 |
| 最近记录 | `GET /api/dashboard/recent?limit=10` | 类型、标题、操作人、时间、缩略图、状态 | 进入页面/新增后 |
| 快捷入口 | 静态配置 | 模块路由映射 | 无 |
