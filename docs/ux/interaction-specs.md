## 2. 表单校验交互规范

### 2.1 校验时机矩阵

```
┌────────────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│ 校验类型           │ 即时         │ 失焦         │ 提交时       │ 服务端       │
│ (触发时机)         │ (onChange/   │ (onBlur)     │ (onSubmit)   │ (异步/唯一)  │
│                    │ debounce)    │              │              │              │
├────────────────────┼──────────────┼──────────────┼──────────────┼──────────────┤
│ 必填非空           │              │      ✅       │      ✅       │              │
│ 格式/正则          │   ✅ (300ms) │      ✅       │      ✅       │              │
│ 长度范围           │   ✅ (实时)  │              │      ✅       │              │
│ 数值范围           │   ✅ (300ms) │              │      ✅       │              │
│ 日期范围           │              │      ✅       │      ✅       │              │
│ 跨字段依赖         │              │      ✅       │      ✅       │              │
│ 条件显示字段       │              │   (显示时)    │      ✅       │              │
│ 唯一性 (批号/证件号)│             │              │              │      ✅       │
│ 业务规则复杂       │              │              │              │      ✅       │
└────────────────────┴──────────────┴──────────────┴──────────────┴──────────────┘
```

### 2.2 视觉反馈时序

```
即时校验 (防抖 300ms)：
用户输入 → 300ms 无新输入 → 校验 → 
  通过：右侧显示 ✅ 绿色勾 (可选，轻量) / 字符计数更新
  失败：边框变红，右侧 ❌，下方错误文本 (不阻断输入)

失焦校验：
用户离开字段 → 立即校验必填/格式/业务规则 →
  通过：边框恢复默认，错误清除
  失败：边框红，错误文本显示，聚焦不丢失 (用户可继续修正)

提交校验：
点击提交按钮 → 全字段校验 (含未触发过的) →
  有错误：阻止提交，页面滚动到首个错误字段 (平滑 300ms)，该字段聚焦，Toast "表单验证失败，请检查 X 处错误"
  无错误：按钮 Loading，发起请求

服务端校验失败：
请求返回 422/400 → 映射字段错误码 → 对应字段显示服务端错误文本 → Toast "保存失败：{汇总信息}"

长辈模式差异：
- 即时校验延迟 500ms
- 错误文案大字号 16px，红色加粗
- 提交失败：全屏顶部大号 Toast + 语音播报 + 自动滚动 + 震动
- 成功：大号成功 Toast 居中 3 秒 + 语音播报
```

### 2.3 错误文案规范化

```
文案模板变量：
{field} = 字段显示名 (如"药品名称")
{value} = 用户输入值
{min} {max} = 限制值
{pattern} = 格式描述

标准错误码 → 文案映射：
├── required: "{field}不能为空"
├── minLength: "{field}至少需要{min}个字符"
├── maxLength: "{field}不能超过{max}个字符"
├── pattern: "{field}格式不正确，{pattern}"
├── min: "{field}不能小于{min}"
├── max: "{field}不能大于{max}"
├── range: "{field}必须在{min}到{max}之间"
├── dateAfter: "{field}必须晚于{referenceField}"
├── dateBefore: "{field}必须早于{referenceField}"
├── unique: "{field}「{value}」已存在，请更换"
├── dependency: "当{depField}为{depValue}时，{field}必填"
├── maxFiles: "最多上传{max}张图片"
├── maxFileSize: "单张图片不能超过{maxSize}MB"
├── fileType: "仅支持{types}格式的图片"
└── custom: {后端返回的业务错误文案}

特殊场景文案：
├── 网络错误: "网络不给力，请检查连接后重试"
├── 超时: "请求超时，请稍后重试"
├── 无权限: "您没有权限执行此操作"
├── 数据冲突: "数据已被他人修改，请刷新后重试"
├── 会话过期: "登录已过期，请重新登录"
└── 未知错误: "操作失败，请稍后重试或联系客服"
```

## 3. PWA 场景交互规范

### 3.1 安装引导 (Add to Home Screen)

```

✅ 用户访问 ≥ 2 次 (localStorage 记录)

✅ 支持 beforeinstallprompt 事件 (Chrome/Edge/移动端浏览器)
✅ 未在 7 天内拒绝过

显示时机：
- 满足条件后，下一次访问页面加载完成 3 秒后显示
- 或在首页仪表盘、设置中心显示固定入口
```

### 3.4 后台同步与推送

```
│   └── 系统通知 (版本更新/维护)
├── Payload：加密数据，含 title/body/icon/actions/data
├── Actions：打开应用/标记已读/稍后提醒/跳转详情
├── 点击处理：notificationclick → clients.openWindow('/todo/detail/:id')
└── 退订：设置中心可关闭各类推送

长辈模式推送：
- 标题大字号，正文简洁
- 行动按钮：大图标+大字"查看"、"稍后"
- 关键提醒（过期/截止）高优先级，震动+铃声

```

```
├── 锁定提示：他人正在编辑 → 当前用户进入只读预览模式，顶部提示"李四正在编辑，您正在预览"
├── 变更推送：WebSocket 推送 → 列表页实时更新 / 详情页字段高亮变化 2 秒
└── 冲突合并：保存时检测冲突 → 三方合并 / 手动解决

长辈模式：简化为"有人正在编辑，请稍后再试" 大号 Toast
```

## 7. 性能交互指标

### 7.1 关键交互响应时间 (RAIL 模型)

```
Response (响应) - 用户输入到视觉反馈：
├── 点击按钮 → 按钮 Active 态：< 50ms
├── 点击链接 → 页面开始转场：< 100ms
├── 输入文字 → 字符显示：< 16ms (1 帧)
├── 点击展开 → 面板动画开始：< 100ms
└── 长辈模式：所有阈值 × 1.5

Animation (动画) - 60fps 稳定：
├── 页面转场：200-300ms，无掉帧
├── 列表滚动：60fps，惯性滚动自然
├── 图片缩放：60fps，无卡顿
├── Skeleton 骨架：脉冲动画平滑
└── 长辈模式：减少动画，优先保证操作响应

Idle (空闲) - 利用空闲时间预加载：
├── 路由预加载：hover 菜单项 100ms → 预加载目标页 JS/数据
├── 图片预加载：视口外 500px 开始加载
├── 数据预取：列表页进入 → 预取详情页数据
└── Service Worker：空闲期更新缓存

Load (加载) - 关键路径：
├── 首屏可交互 (TTI)：< 3s (4G) / < 5s (3G)
├── 首屏内容绘制 (FCP)：< 1.5s
├── 最大内容绘制 (LCP)：< 2.5s
├── 累积布局偏移 (CLS)：< 0.1
└── 首次输入延迟 (FID)：< 100ms
```

### 7.2 加载状态分级

```
Level 1 - 瞬时 (< 200ms)：无 Loading，直接切换
Level 2 - 快速 (200ms - 1s)：按钮/链接 Loading 态，骨架层
Level 3 - 一般 (1s - 3s)：区域 Skeleton + 进度条
Level 4 - 慢速 (> 3s)：全屏 Loading + 进度百分比 + 取消按钮
Level 5 - 极慢/失败 (> 10s / Error)：空状态页 + 重试 + 离线提示

长辈模式：Level 阈值下调 30%，更早显示 Loading 反馈
```

## 8. 交互规范交付清单 (给前端/测试)

### 8.1 必须实现的交互清单

```
□ 响应式导航：Desktop 侧边栏 / Tablet 可折叠 / Mobile 抽屉 + TabBar
□ 面包屑导航 (Desktop/Tablet) + 返回按钮
□ 表单校验：即时/失焦/提交/服务端 四层校验 + 错误汇总
□ 离开保护：脏状态检测 + 确认 Modal (标准/长辈双版本)
□ 图片上传：相机/相册/扫码/拖拽 + 预览/裁剪/压缩 + 进度/断点续传
□ 成员选择器：单选/多选/含全员 + 桌面下拉/移动抽屉
□ 日期时间选择：日期/时间/日期时间/范围 + 快捷选项
□ 搜索筛选：实时建议/历史/高级筛选面板 + URL 同步
□ PWA 安装引导：条件触发/横幅/模态/设置中心入口
□ 离线支持：缓存策略/离线页/操作队列/后台同步/状态指示
□ 推送通知：权限请求/订阅管理/多场景/点击跳转
□ 快捷方式：桌面图标长按菜单
□ 乐观更新：完成/收藏/标签/排序等高频操作
□ 实时协作：在线指示/光标/锁定/变更推送 (可选)
□ 微交互：所有按钮/输入/卡片/弹层/导航的动效
□ 手势交互：左滑/下拉刷新/画廊/拖拽关闭

```
