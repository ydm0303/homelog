# 家记 - 适老化/无障碍专项规范

## 1. 适老模式总览

### 1.1 开启入口与生效范围

```
开启位置：
├── 设置中心 → ♿ 适老化设置 → [开启适老模式] 主开关
├── 登录页 → 长辈模式快捷入口 (底部固定)
├── 成员管理 → 编辑成员 → 角色选择"只读/长辈" → 自动建议开启
└── 首次登录引导 → 检测用户年龄/设备辅助功能 → 主动推荐

生效范围：全局即时生效，无需刷新
├── CSS 变量覆盖：[data-elderly="true"] 选择器
├── 组件 Props 透传：large/simple/accessible 模式
├── 路由守卫：长辈角色用户自动注入 elderly=true
└── 本地存储：localStorage.setItem('elderlyMode', 'true') 持久化

关闭方式：
├── 设置中心 → 关闭主开关
├── 顶部浮动条"退出适老模式" (开启后持续显示 3 天)
└── 手势：三指双击 (移动端) / Ctrl+Shift+E (桌面端)
```

## 2. 少输入策略 (Reduce Input)

### 2.1 拍照/相机优先

```
适用场景：
├── 药品新增/编辑 → 封面图/说明书 → [📷 拍照识别] 一键直达相机
├── 证件新增/编辑 → 正反面照片 → [📷 拍照] 自动裁边增强
├── 记事新增/编辑 → 图片上传 → [📷 拍照] 连拍模式
├── 自定义表单 → image 字段 → 默认打开相机
└── 通用图片上传组件 → longPress/elderly 模式 → 相机优先

交互流程 (长辈模式)：
1. 点击上传区域 → 直接唤起原生相机 (不显示选择菜单)
2. 拍照完成 → 自动预览 → [✅ 使用照片] / [🔄 重拍] 大按钮
3. 可选：识别文字 (OCR) → 自动填入对应字段 → [确认] / [编辑]
4. 多图场景：连拍模式，拍完一张自动进入下一张，完成点[完成]

技术实现：
<input type="file" accept="image/*" capture="environment" />
// capture="environment" 优先后置摄像头
// capture="user" 前置摄像头
```

### 2.2 扫码/条码识别

```
适用场景：
├── 药品录入 → 扫描药品包装条码 → 自动填入：名称、规格、厂家、批号、有效期
├── 证件录入 → 扫描身份证/护照 MRZ 码 → 自动填入字段
├── 待办/记事 → 扫描二维码 → 识别链接/文本 → 自动填入
├── 成员邀请 → 扫描邀请二维码 → 直接加入家庭
└── 自定义表单 → 扫码字段 → 批量录入

交互：
[📷 扫码] 按钮 → 全屏扫码界面 (大扫描框、高对比度)
→ 识别成功 → 震动反馈 + 声音提示 → 自动填充表单 → Toast "已自动填入 X 项"

技术：
- Web Barcode API / QuaggaJS / html5-qrcode
- 药品条码：对接国家药品监督管理局数据库 (可选)
- 证件 MRZ：ICAO 9303 标准解析
```

## 4. 防误操作设计

### 4.1 删除/销毁性操作二次确认

```
标准模式 (两次确认)：
1. 点击删除 → Popconfirm 气泡确认
   "确定删除「阿莫西林胶囊」吗？删除后不可恢复"
   [取消] [确定删除] (危险色)

2. 批量删除 → Modal 模态框
   标题：确定删除选中的 3 条记录？
   内容：阿莫西林胶囊、布洛芬缓释胶囊、维生素D滴剂
   勾选：[☐ 同时清空关联的图片附件]
   [取消] [确定删除] (危险色)

长辈/简化模式 (单次确认 + 撤销)：
1. 点击删除 → 直接执行删除
2. 顶部/底部 Toast 提示：✅ 已删除「阿莫西林胶囊」 [撤销] (5秒)
3. 点击撤销 → 恢复记录，Toast "已恢复"

配置项 (设置中心 → 适老化设置)：
[☐ 简化删除确认]  开启后：删除仅需单次确认，提供 5 秒撤销窗口
[☐ 危险操作震动反馈]  移动端删除/归档触发震动
[☐ 重要操作语音确认]  (后期) 删除前语音播报"即将删除xxx，确定吗？"
```

### 4.2 重要操作 Toast 撤销机制

```
适用操作：
├── 删除记录 (单条/批量)
├── 归档记录
├── 标记待办完成/取消完成
├── 移除成员
├── 取消关联/取消收藏
├── 清空草稿
└── 导入覆盖数据

Toast 结构：
┌─────────────────────────────────────────────────────────────────────────────┐
│ ✅ 已删除「阿莫西林胶囊」                              [撤销]  [✕]           │
│    5 秒后自动消失  ████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
└─────────────────────────────────────────────────────────────────────────────┘

行为规范：
├── 显示时长：5 秒 (长辈模式 8 秒)
├── 进度条：实时倒计时，悬停暂停
├── 撤销点击：立即执行逆操作，Toast 更新为"已撤销" 2 秒后消失
├── 多操作叠加：最多同时显示 3 个，新增顶部插入
├── 键盘可达：Tab 聚焦撤销按钮，Enter 触发
└── 屏幕阅读器：aria-live="assertive" 立即宣告
```

```
├── 数据导入覆盖/清空数据
├── 修改密码/关闭 2FA
├── 解绑微信/撤销所有设备
└── 关闭适老模式 (长辈自身操作)

确认模式：
标准：Modal 二次确认 + 危险操作红色按钮 + 输入确认词 (如"解散家庭")
长辈：大字号 Modal + 语音播报确认内容 + 单次大按钮确认 + 5 秒撤销 Toast
```

## 5. 无障碍 (Accessibility) 规范 - WCAG 2.1 AA

### 5.1 语义化 HTML 结构

```
页面结构：
<header role="banner">          ← 顶部 AppBar/导航
<nav role="navigation" aria-label="主导航">  ← 侧边栏/抽屉菜单
<main role="main">              ← 页面主内容 (唯一)
<aside role="complementary">    ← 侧边栏面板/右侧面板
<footer role="contentinfo">     ← 底部版权/TabBar
<section aria-labelledby="..."> ← 各功能区块
<article>                       ← 列表项/卡片/记录详情

标题层级 (严格递增)：
h1: 页面主标题 (仅 1 个)
h2: 一级区块标题 (如"基础信息""图片画廊")
h3: 二级区块标题 (如"用法用量""库存信息")
h4: 字段组标题 (如"服用时间设置")

地标角色：
- 搜索框：<form role="search">
- 面包屑：<nav aria-label="面包屑导航">
- 分页：<nav aria-label="分页导航">
- 标签页：<div role="tablist"> + <button role="tab">
- 对话框：<div role="dialog" aria-modal="true" aria-labelledby="title">
- 提示：<div role="tooltip" id="..."> + aria-describedby
- 进度条：<div role="progressbar" aria-valuenow="50" aria-valuemin="0" aria-valuemax="100">
- 状态消息：<div role="status" aria-live="polite"> / <div role="alert" aria-live="assertive">
```

### 5.2 键盘可达性

```
Tab 键顺序：逻辑阅读顺序 (左上 → 右下)
焦点指示器：可见、高对比度、不依赖颜色
├── Outline: 2px solid var(--color-primary-500) + 2px offset
├── 不使用 outline: none (除非自定义更明显)
└── 焦点陷阱：Modal/Drawer 打开时，Tab 循环在内部

快捷键 (桌面端)：
├── Alt+1~5: 快速切换主模块 (仪表盘/药品/待办/记事/证件)
├── Alt+N: 新增当前模块记录
├── Alt+S: 焦点跳转到搜索框
├── Alt+F: 焦点跳转到筛选区
├── /: 焦点跳转到搜索框 (非输入框时)
├── ESC: 关闭 Modal/Drawer/下拉/Tooltip
├── Enter/Space: 激活按钮/链接/复选框/单选框
├── 方向键: 菜单/下拉/标签页/日期选择器内部导航
├── Home/End: 列表首尾、输入框首尾
└── Ctrl+S: 保存表单 (防冲突浏览器保存页面)

跳过链接 (页面顶部隐藏，聚焦显示)：
<a href="#main-content" class="skip-link">跳转到主要内容</a>
<a href="#navigation" class="skip-link">跳转到导航菜单</a>
<a href="#search" class="skip-link">跳转到搜索框</a>
```

### 5.3 屏幕阅读器支持

```
ARIA 标签完整性：
├── 所有表单控件：关联 <label for="id"> 或 aria-label/aria-labelledby
├── 图标按钮：aria-label="删除记录" / aria-labelledby="delete-label"
├── 状态指示：aria-live="polite" (Toast/加载完成) / aria-live="assertive" (错误/删除确认)
├── 展开/折叠：aria-expanded="true/false" + aria-controls="panel-id"
├── 选中状态：aria-selected="true/false" (Tab/列表项/树节点)
├── 禁用状态：aria-disabled="true" (配合 disabled 属性)
├── 必填项：aria-required="true" + 视觉 * 标记
├── 错误关联：aria-invalid="true" + aria-describedby="error-id"
├── 当前项：aria-current="page/step/location/date/time" (面包屑/分页/步骤条/日历)
└── 描述关联：aria-describedby="help-id" (帮助文本/字符计数/错误信息)

命名规范：
├── 按钮：动词 + 名词 "删除记录" "编辑药品" "新增待办" (不含"按钮"二字)
├── 链接：目的地/动作 "查看药品详情" "前往设置中心" "下载导入模板"
├── 图片：alt 传达信息内容，装饰性 alt=""
├── 表单组：<fieldset><legend>用法用量</legend>... 组织相关单选/复选
└── 表格：<caption>药品列表 (共 24 条)</caption> + <th scope="col/row">

动态内容通知：
├── 列表数据更新：aria-live="polite" 容器，内容变化自动播报"列表已更新，共 24 条"
├── 表单校验错误：aria-live="assertive" 立即播报"表单验证失败，药品名称不能为空"
├── 加载状态：aria-busy="true" + 进度条 role="progressbar"
├── 删除操作：执行前 aria-live="assertive" 播报"正在删除阿莫西林胶囊"，完成后"已删除"
└── 页面路由变化：单页应用路由切换 → 焦点移至主标题 h1 → 播放报页面标题
```

### 5.4 颜色与对比度

```
WCAG AA 标准 (最低)：
├── 正常文本 (≤18px 或 ≤14px bold)：对比度 ≥ 4.5:1
├── 大号文本 (>18px 或 >14px bold)：对比度 ≥ 3:1
├── UI 组件边框/图标：对比度 ≥ 3:1
└── 焦点指示器：对比度 ≥ 3:1

当前色板验证 (标准模式)：
├── 主色 #008F73 on 白 #FFFFFF：5.2:1 ✅
├── 主色文本 #005645 on 浅色 #E6F4F1：6.8:1 ✅
├── 成功色 #52C41A on 白：3.1:1 ⚠️ 大号文本用 ✅ / 正常文本需加深
├── 警告色 #FAAD14 on 白：2.1:1 ❌ → 调整为 #D48806 (4.6:1) ✅
├── 错误色 #F5222D on 白：4.8:1 ✅
├── 次要文本 #8C8C8C on 白：3.9:1 ⚠️ → 调整为 #737373 (4.5:1) ✅
├── 占位符 #BFBFBF on 白：2.3:1 ❌ → 仅占位符允许，输入时变正常色
└── 边框 #D9D9D9 on 白：1.4:1 ❌ → 组件边框需 ≥3:1，调整为 #BFBFBF (2.3:1) 仍不足
    → 解决：Focus 态主色边框 2px + 阴影，不依赖边框色对比度

高对比度模式 (适老/无障碍开启)：
[data-high-contrast="true"] {
  --color-text-primary: #000000;
  --color-text-secondary: #000000;
  --color-text-tertiary: #333333;
  --color-border-base: #000000;
  --color-primary-500: #004422;
  --color-success-500: #006600;
  --color-warning-500: #884400;
  --color-error-500: #880000;
  --color-bg-page: #FFFFFF;
  --color-bg-base: #FFFFFF;
}
```

### 5.5 响应式与缩放支持

```
浏览器缩放 200% 无水平滚动：
├── 视口单位：rem 基准 16px，缩放跟随
├── 容器查询：@container (min-width: 320px) 调整布局
├── 文本不截断：word-wrap: break-word, overflow-wrap: anywhere
├── 表格横向滚动：容器 overflow-x: auto，表格 min-width 保证可读
└── 固定定位元素：不遮挡主要内容，z-index 管理

文本间距 (WCAG 1.4.12)：
用户自定义样式表覆盖时不丢失功能：
├── 行高 ≥ 1.5 倍字号
├── 段落间距 ≥ 2 倍字号
├── 字间距 ≥ 0.12 倍字号
├── 词间距 ≥ 0.16 倍字号
└── 实现：不使用 !important 固定行高/间距，使用相对单位
```

### 5.6 动效与闪烁控制

```
prefers-reduced-motion 支持：
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

自动播放控制：
├── 视频/音频：不自动播放，或静音自动播放 + 显式控件
├── 轮播图：默认不自动轮播，或提供暂停按钮
├── 加载动画：必要反馈保留，装饰性动画尊重偏好
└── 闪烁：无 3Hz 以上闪烁内容

长辈模式 = 隐式 prefers-reduced-motion
```

## 6. 长辈模式专项交互细则

### 6.1 导航简化

```
侧边栏/抽屉菜单：
├── 仅显示有权限的模块，隐藏设置中心入口 (或放入用户菜单)
├── 图标 + 大字标签，无次要文字描述
├── 当前模块高亮：背景色块 + 字重加粗
├── 点击模块 → 直接进入列表页 (无下拉展开)
└── 底部固定：[🏠 首页] [👤 我] 两个大按钮

面包屑：隐藏 (节省空间，减少认知)
TabBar (移动端)：固定显示 3-4 核心模块，其它进"更多"
```

### 6.2 列表页简化

```
默认卡片视图 (非表格)
单行核心信息：标题 + 关键状态 + 时间
隐藏：次要字段、操作列、复选框、分页器
操作：长按 800ms → 大号操作菜单 (查看/编辑/删除)
分页：无限滚动加载更多，底部大号"加载更多"按钮
空状态：大插画 + 大字文案 + 全宽大按钮
```

### 6.3 详情页简化

```
默认展开所有折叠面板
隐藏：操作日志、创建/更新时间、ID、权限标记
字段标签：加粗 + 16px
字段值：20px + 高对比度
图片：大缩略图 120px，点击全屏 (无画廊切换动画)
关联记录：仅显示标题 + 类型图标，点击跳转
```

### 6.4 编辑页简化

```
字段分组折叠 → 默认全部展开
必填项：红色 * 号 + "必填" 文字标签
输入框：全宽、高 56px、字号 20px、圆角 12px
选择器：全屏底部抽屉、大选项 48px 高
图片上传：相机优先、拍完自动下一张、大按钮"完成"
成员选择：大头像卡片、单选模式点击即选
日期/时间：分步选择 (先日期再时间)、大日历面板
提交：底部固定双大按钮 [保存草稿] [确定保存]
校验错误：全屏顶部大号 Toast + 自动滚动到首个错误字段 + 语音播报
```

### 6.5 反馈强化

```
Toast：居中全屏宽、大字号、停留 5 秒、带进度条、语音播报
Modal：全屏化、标题 24px、内容 20px、按钮 56px 高
加载：全屏大 Spinner 48px + "加载中..." 20px
成功/失败：大图标 64px + 大字文案 + 震动 + 语音
```
